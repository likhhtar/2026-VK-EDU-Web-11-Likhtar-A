How to center a div horizontally and vertically in CSS?

I'm trying to center a div both horizontally and vertically within its parent container. I've tried using margin: auto but it only centers horizontally.

Here's my current HTML:

<div class="parent">
  <div class="child">
    Content to be centered
  </div>
</div>

And my CSS:

.parent {
  width: 100vw;
  height: 100vh;
  background-color: #f0f0f0;
}

.child {
  width: 200px;
  height: 100px;
  background-color: #007bff;
  margin: auto; /* Only centers horizontally */
}

What's the best modern approach to achieve both horizontal and vertical centering? I've heard about flexbox and CSS Grid, but I'm not sure which one to use or how to implement them properly.

css_expert answered 1 hour ago
Correct Answer

The best modern approach is to use Flexbox. It's widely supported and very straightforward:

.parent {
  display: flex;
  justify-content: center; /* Horizontal centering */
  align-items: center;     /* Vertical centering */
  width: 100vw;
  height: 100vh;
  background-color: #f0f0f0;
}

.child {
  width: 200px;
  height: 100px;
  background-color: #007bff;
}

This method:

  • Works in all modern browsers
  • Is responsive by default
  • Handles content of any size
  • Is easy to understand and maintain

Alternative using CSS Grid:

.parent {
  display: grid;
  place-items: center;
  width: 100vw;
  height: 100vh;
  background-color: #f0f0f0;
}

You can also use the traditional approach with absolute positioning:

.parent {
  position: relative;
  width: 100vw;
  height: 100vh;
  background-color: #f0f0f0;
}

.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 200px;
  height: 100px;
  background-color: #007bff;
}

This method works well but is less flexible than flexbox. The transform: translate(-50%, -50%) moves the element back by half its width and height.

frontend_dev answered 15 minutes ago

For a more modern approach, you can use CSS Grid with place-items:

.parent {
  display: grid;
  place-items: center;
  width: 100vw;
  height: 100vh;
  background-color: #f0f0f0;
}

.child {
  width: 200px;
  height: 100px;
  background-color: #007bff;
}

CSS Grid is excellent for complex layouts, but for simple centering, flexbox is usually preferred due to better browser support and simpler syntax.
